# Contributions

Fixes, reproductions and tests are welcome under MPL-2.0. Preserve third-party
notices and describe the tested SDK version, board and expected behavior.
Do not submit vendor binary code, decompiler output, credentials or flash backups.

Distributed modifications to covered files must be available to recipients
under MPL-2.0. Separate application files can remain proprietary, and private
changes need not be shared. Upstream PRs are encouraged, not legally required.
